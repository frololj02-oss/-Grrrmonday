## 1. Общее описание
Консольный эмулятор (CLI) языка оболочки UNIX-подобной ОС, реализованный на языке Python. Поддерживает интерактивный режим диалога (REPL), выполнение стартовых скриптов с остановкой при первой ошибке и работу с виртуальной файловой системой (VFS) в оперативной памяти, загружаемой из XML-файлов (данные файлов кодируются в `base64`).

## 2. Описание всех функций и настроек

### Параметры командной строки:
* `--vfs <путь>` — путь к XML-файлу виртуальной файловой системы (по умолчанию `tests/vfs_deep.xml`).
* `--script <путь>` — путь к стартовому скрипту для автоматического выполнения команд.

### Поддерживаемые команды эмулятора:
* `ls [путь]` — вывод списка файлов и папок в текущем или указанном каталоге VFS.
* `cd [путь]` — переход в указанный каталог VFS (поддерживаются абсолютные и относительные пути, `.` и `..`).
* `head [-n ЧИСЛО] <файл>` — вывод первых строк файла из VFS (по умолчанию 10 строк).
* `clear` — очистка экрана консоли.
* `mkdir <имя>` — создание нового каталога в оперативной памяти VFS.
* `vfs-info` — вывод имени загруженной VFS и SHA-256 хеш-суммы исходного XML-файла.
* `help` — вывод справочной информации о доступных командах.
* `exit` — завершение работы эмулятора.

## 3. Команды для сборки проекта и запуска тестов

Запуск в интерактивном режиме через скрипт запуска:
```bat
.\run.bat
```

Запуск с указанием VFS и стартового скрипта:
```bat
python src/emulator.py --vfs tests/vfs_deep.xml --script tests/start_stage5.txt
```

Запуск пакетного тестирования всех вариантов VFS (минимальный, средний, 3+ уровня вложенности):
```bat
.\tests\test_stage3.bat
```

Запуск модульных тестов:
```bat
python -m unittest discover -s tests
```
